# Source-grounded metadata

Keep curated sample/donor mapping tables and evidence here, with explicit source
accession, source filename, source key and citation/table reference for clinical
fields. Join using a documented key, checking duplicates and unmatched cells.
Unknown values remain NA, including donor identity, control status, FCD subtype
and mutation status. Do not interpret sample-name patterns as clinical evidence.
The archived Kumar dictionary is a lead to verify, not approved metadata.
